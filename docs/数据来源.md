# 官方赛程数据来源

本文记录观赛搭子使用的公开赛程源、字段解释和失败处理方式。官方接口可能变化；这是实现依据和核验记录，不是对官方数据持续可用或字段稳定的承诺。

## 来源与引用链

项目从 [英雄联盟赛事官网 lpl.qq.com](https://lpl.qq.com/) 读取赛程。开发时核验的官方引用链为：

1. 官方首页引用前端脚本 [`/web202301/js/index.js`](https://lpl.qq.com/web202301/js/index.js)。
2. 该脚本的 `InitLatestBMatch` 方法引用赛程地址：

   ```text
   https://lpl.qq.com/web201612/data/LOL_MATCH2_MATCH_HOMEPAGE_BMATCH_LIST.js
   ```

3. 该地址返回包含 `status`、`lastUpTime` 和 `msg` 的 **JSON 文档**。文件后缀是 `.js`，但应用只使用 JSON 解析器读取内容，**不执行或 eval 下载的 JavaScript**。

请求不需要官方账号。应用不接入 Riot 或腾讯账户，也不请求玩家个人数据。赛程仅在用户主动查询时获取，并使用短时内存缓存减少重复请求。

当前适配器只接受固定官方数据地址，不允许由备份或页面输入任意抓取 URL。请求有超时和响应体大小限制；只有顶层成功状态、列表结构和所需字段可识别时，才进入导入流程。

## 按日期筛选

用户选择 `YYYY-MM-DD` 格式的日期。官方 `MatchDate` 是形如 `2026-10-24 01:00:00` 的时间字符串，应用将其解释为**北京时间 UTC+8**，并返回带时区的时间，例如：

```text
2026-10-24T01:00:00+08:00
```

这个时刻在 UTC 中是 2026-10-23 17:00，两个时间并不矛盾。为避免海外比赛的跨日混淆，同步选择、日期筛选和赛程展示使用北京时间口径。

官方源含全球总决赛、LPL、MSI 和其他已公布的英雄联盟赛事。应用排除云顶之弈记录，按可识别的对阵与支持赛制整理结果。`bGameId` 是赛事类型，不能将其值 `1` 当成英雄联盟游戏的总开关；不同赛事类型仍可能都是英雄联盟比赛。

没有该日可用比赛时，不会自动改用相邻日期，也不会插入示例对阵。

## 字段解释

| 官方字段 | 用途与处理 |
| --- | --- |
| `status` | 顶层成功状态为 `"0"`；其他状态或结构异常作为源错误处理 |
| `lastUpTime` | 官方给出的数据更新时间，仅用于核对来源，不代表所有未来对阵已公布 |
| `msg` | 比赛记录列表 |
| `isTft` | 用于排除云顶之弈赛程 |
| `bGameId` | 赛事大类编号，如全球总决赛、职业联赛、季中冠军赛；不等同于游戏种类 |
| `bMatchId` | 官方比赛编号，保存在本地以去重 |
| `bMatchName` | 已公布时通常为 `GEN vs IG`；对阵未定时可能只有 `D2G1` 等占位名称 |
| `TeamA` / `TeamB` | 官方队伍编号；`0`、`297` 等待定值不作为可预测对阵 |
| `TeamShortNameA` / `TeamShortNameB` | 部分记录为空，不能单独依赖 |
| `GameId` / `GameName` | 具体赛事编号与赛事名称 |
| `GameTypeName` / `GameProcName` | 阶段与轮次，用于组织显示文本 |
| `GameModeName` | 赛制文本，例如 BO1、BO3、BO5；BO2 当前不用于单场胜负预测 |
| `GameMode` | 赛制文本缺失时的已核对备用值：1→BO1、3→BO3、4→BO5 |
| `MatchDate` | 北京时间的官方开赛时间 |
| `MatchStatus` | 官方比赛状态，映射见下表 |
| `ScoreA` / `ScoreB` | 官方进行中或结束状态下的比分，仅作核对信息 |

官方首页脚本的注释与分支对应：

| `MatchStatus` | 官方状态 | 本地读取含义 |
| --- | --- | --- |
| `"1"` | 未开始 | `upcoming` |
| `"2"` | 进行中 | `ongoing` |
| `"3"` | 已结束 | `finished` |
| 其他 | 未知 | `unknown`，不猜测最终获胜队伍 |

队名优先从已公布的 `bMatchName` 拆分；若不符合对阵格式，再尝试非空的官方短名称。空名、相同队名、TBD、待定或其他不可识别占位不允许成为有效预测对象。官方另有队伍映射数据 `LOL_MATCH2_TEAM_LIST.js`，调查时用于核对 TeamId，但当前同步流程不需要执行该文件。

## 无赛程和失败处理

| 情况 | 行为 |
| --- | --- |
| 日期格式无效或不存在 | 提示重新选择日期，不请求或导入比赛 |
| 所选日期无可用记录 | `NO_SCHEDULE`：说明官方尚未公布或该日无比赛 |
| 官方只公布时间、完整对阵仍待定 | `NO_CONFIRMED_MATCHES`：等待队伍确认后再同步 |
| 只有不支持的赛制可用 | `UNSUPPORTED_FORMAT`：明确说明暂不支持，不改造成其他赛制 |
| 部分记录对阵未定或字段异常 | 仅预览有效记录，并提示跳过的条目 |
| 网络错误、超时或官方服务不可用 | `SOURCE_UNAVAILABLE`：提示稍后重试，不添加比赛 |
| 官方响应不是预期 JSON、状态或字段发生变化 | `SOURCE_FORMAT_CHANGED`：停止导入，不猜测字段含义 |

## 对本机数据的影响

- 只有用户预览后选择并确认的比赛才导入。
- 新比赛双方赔率为空。**本项目不从官方或第三方抓取赔率，也不推荐或自动生成赔率。**
- 官方编号用于去重。重复同步不覆盖人工赔率，更不会改变已有预测的锁定赔率。
- 有下注历史的对局，如果官方对阵、阶段或赛制与本机记录冲突，会跳过更新，避免历史账目含义发生变化。
- 结算或取消后的比赛不因再次同步而自动更改。
- 已开始、官方进行中或已结束的比赛导入后保持封盘；重新同步不会自动开放已经封盘的比赛。
- 官方状态与比分仅作赛果核对。**用户仍需手动确认获胜队伍，系统才会结算虚拟积分。**
